# Paseo Link Handler

Этот HTTPS-переходник нужен, чтобы добавить ссылку на агента Paseo прямо в задачу Multica. В URL-свойство задачи помещается обычная ссылка `https://`; при открытии она запускает соответствующий deep link `paseo://` в desktop-приложении Paseo. Так команда может перейти к нужному агенту из свойств задачи, даже если `paseo://` нельзя разместить напрямую.

Ссылка вида

```text
https://go.example.com/paseo/h/<server-id>/agent/<agent-id>
```

открывает deep link:

```text
paseo://h/<server-id>/agent/<agent-id>
```

## Как это работает

- Traefik принимает HTTPS-запросы к `/paseo/h/<server-id>/agent/<agent-id>` и передаёт их Nginx.
- Страница проверяет путь и пытается запустить Paseo через скрытый `iframe`.
- На странице остаётся кнопка «Открыть Paseo» на случай, если браузер заблокировал автоматический запуск.
- Через пять секунд страница пробует закрыть вкладку. Браузер может запретить автоматическое закрытие; тогда вкладку можно закрыть вручную.

## Файлы

- `docker-compose.yml` — Compose-конфигурация сервиса из Dokploy; HTML-страница и конфигурация Nginx включены в неё.
- `traefik/paseo-redirect.yml` — пример динамического правила Traefik для домена `go.example.com`.

## Развёртывание

Compose-сервис рассчитан на Dokploy с общей внешней Docker-сетью `dokploy-network` и Traefik Docker provider. Правило из `traefik/paseo-redirect.yml` размещается в каталоге динамической конфигурации Traefik. Для HTTPS нужны DNS-запись домена на сервер и уже настроенный resolver `letsencrypt`.

Перед развёртыванием замените `go.example.com` в Traefik-правиле и URL-примерах на свой домен. Укажите его в DNS и используйте настроенный на сервере TLS resolver. Сервис принимает только указанный формат пути.

## Ограничения браузера

Браузер может потребовать подтверждение открытия внешнего приложения или заблокировать автоматический запуск ссылки. В этом случае нажмите кнопку на странице. Скрипт может закрыть вкладку только если браузер разрешает странице закрывать её.
